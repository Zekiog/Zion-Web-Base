# Security Policy

## Supported code

There are no tagged releases. `main` is the default branch.

## Reporting a vulnerability

Do not open a public GitHub issue for a security vulnerability.

Use the **Report a vulnerability** button on the repository **Security** tab. That creates a private advisory for the maintainer.

Include the affected file, the steps to reproduce the problem, and what it would allow.

## Scope

Reports about files, configuration, and workflows in this repository are in scope.

Report bugs in upstream dependencies to those projects. Reports that need physical access to a machine, and reports that are only social engineering, are out of scope.
