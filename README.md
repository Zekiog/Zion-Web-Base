## 🚀 Quick Start

### Prerequisites
- Node.js 18+ ([Download](https://nodejs.org))
- npm or yarn
- Git

### Installation

```bash
# Clone repository
git clone git@github.com:ZeZilly/Zion-Web-Base.git
cd Zion-Web-Base

# Install dependencies
npm install

# Setup environment variables
cp .env.example .env

# Run development server
npm run dev
```

Visit: **http://localhost:5173**
